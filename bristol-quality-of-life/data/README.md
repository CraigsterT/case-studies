# Data folder

| File | What it is | In the repo? |
|------|------------|--------------|
| `bristol_wards.csv` | Lookup of Bristol ward code (`Ward ID`), ward name and number of councillors. Ward codes follow the ONS ward geography. | Yes |
| `Bristol_Quality_of_Life_data_(2024_25).csv` | Bristol City Council Quality of Life survey results by ward. | No, download it yourself (see the main README). |

The report reads both files from the `DataFolder` parameter in Power BI.
